🔐 Уровни доступа

Система использует 5-уровневую модель прав

⭐

Уровень 1-3 Админ

Базовый доступ к админ-панели. Можно редактировать формы, доступные вашему уровню.

👑

Уровень 4-5 Владелец

Полный доступ. Управление администраторами, названиями уровней, просмотр логов.

📝 Управление формами

Создание и редактирование форм для подачи заявок

🆕

Создание формы

Нажмите + Новая форма в админ-панели. Заполните название, эмодзи, минимальный уровень доступа и вопросы.

🎨

Цвет эмбеда

Каждая форма может иметь свой цвет. Выберите цвет через палитру — он будет использоваться в Discord-эмбеде.

🖼️

Thumbnail & Image

Добавьте URL картинки в поле Thumbnail URL (иконка) или Image URL (большая картинка).

📢

Пинг-роль

Укажите ID роли Discord. При отправке заявки эта роль будет упомянута. Работает без выбора отдела.

🏢 Выбор отдела (вложенный список)

Создание опроса с выбором подразделения внутри формы

📋

Формат вопроса

Используйте синтаксис:
Вопрос [Отдел1|ID_роли|Webhook, Отдел2|ID_роли|Webhook]

🔀

Разные вебхуки

Каждый отдел может отправлять заявку на свой вебхук. Если не указан — используется общий.

🔕

Отключение пинга

Используйте 123 как ID роли — пинг не отправится. Пример: Отдел|123|https://...
