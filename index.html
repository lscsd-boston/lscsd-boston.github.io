📖 FAQ — Гайд по системе

Вся информация по использованию портала

📝 Как подать заявку? Пользователь

  • Нажмите на нужную форму на главной странице
  • Заполните все поля, отмеченные *
  • Если есть выбор отдела — выберите нужный
  • При необходимости загрузите файлы (скриншоты, документы)
  • Нажмите «Отправить»

📋 Все ваши заявки доступны в разделе «Мои заявки»

📎 Как загрузить файл? Пользователь

Если в форме есть поле file:Название:

  • Нажмите на область «Загрузить файл»
  • Выберите файл с компьютера (до 5 файлов)
  • Файл отобразится в списке, можно удалить кнопкой ✕

⚠️ Максимальный размер файла: 8 МБ

⚡ Как создать форму? Админ

  • Откройте Админ-панель через боковое меню
  • Нажмите «+ Новая форма»
  • Укажите название, эмодзи, цвет эмбеда
  • Добавьте вопросы (каждый с новой строки)
  • Нажмите «Сохранить»

🏢 Как сделать выбор отдела? Админ

Добавьте вопрос в формате:

Выберите отдел [Отдел1|ID_роли|webhook, Отдел2|ID_роли|webhook]
  • Отдел1 — название кнопки
  • ID_роли — ID Discord-роли для пинга (123 = без пинга)
  • webhook — URL вебхука канала отдела

⚠️ Отделы разделяются запятой с пробелом

🎨 Кастомизация эмбеда Админ

  • Цвет — HEX-цвет левой полосы эмбеда
  • Пинг-роль — ID роли, которая упоминается при заявке
  • Thumbnail URL — маленькая иконка в углу эмбеда
  • Image URL — большая картинка внизу эмбеда

👥 Управление админами Owner

  • Добавление/удаление администраторов по Discord ID
  • Назначение уровня доступа (1-5)
  • Просмотр полного списка админов

🚫 Система банов Админ

  • Бан пользователя по Discord ID
  • Временный бан: 1 час, 24 часа, 7 дней, навсегда
  • Причина бана сохраняется в логах
  • Разбан в один клик
